# Unreal Viewport Navigation — WASD, FPS & Fly Navigation for Blender

**Unreal Viewport Navigation** brings familiar **WASD, FPS-style and fly navigation** to Blender's 3D Viewport. Inspired by workflows in **Unreal Engine 5, Unity, Godot and Maya**, it helps 3D artists, game developers, modelers and animators move through scenes with intuitive keyboard and mouse controls.

Hold the **Right Mouse Button** to look around, use **WASD** to move, orbit around selected objects, or navigate the active camera. Movement, shortcuts, speed, motion and on-screen controls are customizable.

## Key Features

- **WASD / FPS / Fly Navigation** — responsive first-person movement with mouse look.
- **Navigation Presets** — Unreal Engine, Blender, Maya, Unity, Godot and Custom.
- **Custom Key Bindings** — configure movement, mouse buttons, modifiers, orbit and centering.
- **Advanced Orbit** — orbit selected objects with configurable sensitivity, optional wheel zoom and reversed vertical direction.
- **Orbit Centering** — center manually with a key, a viewport shortcut or a sidebar button; optional automatic centering when orbit begins.
- **Camera View Navigation** — move and rotate the active Blender camera.
- **Optional Engine Editor Shortcuts** — Object Mode tools inspired by popular game editors, disabled by default.
- **Quick Tools Sidebar** — Select, Move, Rotate, Scale, Frame and Duplicate.
- **Movement Customization** — sprint, precision, speed limits, acceleration, deceleration and smoothing.
- **Viewport HUD & Crosshair** — configurable speed hints, positions, opacity and crosshair styles.
- **Multilingual Interface** — 15 supported languages.

## Default Controls

| Input | Action |
| --- | --- |
| **RMB + Mouse** | Look around |
| **W / A / S / D** | Move forward / left / backward / right |
| **Q / E** | Move down / up |
| **Shift** | Sprint |
| **Ctrl** | Precision movement |
| **Mouse Wheel** | Adjust movement speed during navigation |
| **Alt + RMB + Mouse** | Orbit around selection |
| **F during Orbit** | Center orbit on selection |
| **Ctrl + Alt + F** | Center orbit in the viewport |
| **Esc during Orbit** | Cancel orbit and restore the previous view |

Change shortcuts in **Edit → Preferences → Get Extensions / Add-ons → Unreal Viewport Navigation**. Editor shortcuts are optional and **off by default** to avoid replacing Blender's usual Object Mode keys.
